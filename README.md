# NotifyHub

An AI-powered Android application that collects, organizes, and summarizes notifications from multiple apps into one clean interface.

> 🚧 This project is currently under development as part of my Android app development and Ai implementation learning journey.

---

## Project Vision

NotifyHub aims to become a smart notification hub capable of:

- Collecting Android notifications
- Organizing notifications by app
- Searching notification history
- Smart filtering
- AI-powered summaries
- Clean Material Design & interface

---

## Tech Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Git & GitHub
